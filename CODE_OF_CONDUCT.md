# Code of Conduct

OpenBlindySir adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that address is the reference; the summary
below is only a convenience and does not replace it.

## Expected behaviour

- Be respectful and welcoming to everyone, whatever their background, identity,
  experience or level of skill.
- Give and receive feedback constructively, and focus on what is best for the project
  and its community.
- Own your mistakes, apologise to those affected, and learn from them.

Harassment, insults, personal or political attacks, sexualised language or imagery,
trolling, and publishing other people's private information without their explicit
permission are not acceptable.

## Scope

This code applies in every project space (repository, issues, pull requests,
discussions, reviews) and whenever someone officially represents the project in
public.

## Reporting and enforcement

The code of conduct is enforced by the maintainer, who is the repository owner.

- Report incidents **privately** to the maintainer, through the contact details on
  their GitHub profile. If no other private channel is available, you can use the
  repository's private reporting form (**Security** tab, **Report a vulnerability**)
  and state that it is a conduct report.
- Abusive comments can also be reported to GitHub with **Report content**.

Every report is reviewed promptly and fairly, and the reporter's privacy is respected.
Consequences follow the Contributor Covenant enforcement guidelines: correction,
warning, temporary ban or permanent ban.
