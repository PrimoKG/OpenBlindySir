# Applicabilité des avis système — 5 octobre 2026

Cette matrice accompagne le [rapport de durcissement](2026-10-05-security-hardening.md). Elle porte uniquement sur les images Docker identifiées dans ce rapport, leur configuration Compose et les chemins actuels du produit. Les conclusions « fonction hors parcours » sont des analyses locales fondées sur les descriptions primaires, le code et les imports natifs ; elles ne corrigent pas les binaires système et ne constituent pas une preuve universelle d’absence de vulnérabilité. Toute nouvelle image, fonction ou modification de configuration demande une nouvelle revue.

Les résultats bruts Grype restent intacts. Les 14 avis uniques de sévérité élevée et les avis moyens sont examinés ci-dessous ; les faibles/négligeables restent visibles avec une qualification séparée. Le risque système résiduel n’est pas automatiquement accepté pour une publication publique.

## Preuves et limites

La base publique Debian complète a été téléchargée depuis une URL fixe, puis rapprochée localement. Aucun inventaire logiciel ni liste ciblée de CVE n’a été envoyé. Les sources et empreintes restent dans `.local/security-scan/advisories`. Les faits runtime/imports ELF et le test DNS sont dans `.local/security-scan/runtime-facts.json`, `native-facts.json` et `resolver-hardening.json`.

La fermeture inspectée comprend les extensions Python installées, les modules natifs standard, libpython et les dépendances de FFmpeg/ffprobe. Le résultat n’équivaut pas à une analyse formelle de tous les appels internes, symboles chargés dynamiquement ou binaires tiers. Les conditions de configuration et les fonctions non utilisées doivent être maintenues.

Les installations natives utilisent leur propre OS et leurs propres bibliothèques : cette matrice ne leur est pas transférable. Le minimum FFmpeg/ffprobe 9.0.2 est maintenant contrôlé, mais leur fournisseur reste responsable des builds et mises à jour ultérieures.
